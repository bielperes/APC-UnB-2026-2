INIT INP
	 STA ELEMENTO

TEST1 SUB MENOSUM
	  BRZ FIM

TEST2 LDA ELEMENTO
	  SUB MAIOR
	  ADD MENOSUM
	  BRP ATUAL

NEXT	  INP
	  STA ELEMENTO
	  BRA TEST1

ATUAL LDA ELEMENTO
	  STA MAIOR
	  BRA NEXT

FIM LDA MAIOR
	OUT
	HLT

MAIOR DAT -1
ELEMENTO DAT
MENOSUM DAT -1
